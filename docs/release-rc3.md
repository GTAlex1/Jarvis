Candidata experimental de JARVIS para Windows. La validación con micrófonos, Discord y juegos reales sigue pendiente.

- Selección persistente de canal y regreso explícito a la última versión estable compatible.
- Seguimiento del cierre de juegos y protección de descargas e instalaciones del launcher.
- Historial con transcripción y confirmación separadas. Protección adicional durante reproducción simultánea.
- Entrada registrada de HoYoPlay cuando no hay un acceso directo específico. El cliente puede pedir pulsar Jugar.

Si utilizas rc.2 o una versión anterior, cierra JARVIS desde la bandeja y usa el ejecutable oficial de esta página como puente. Tus preferencias y datos biométricos se conservan. Después elige Canal experimental en la bandeja para recibir las siguientes candidatas.
